# santiblr

Portfolio website featuring About and Resume tabs.

## Features

- **Modern, responsive design** with gradient purple background
- **Tab navigation** between About and Resume sections
- **Fully accessible** with ARIA attributes for screen readers
- **Smooth animations** and hover effects
- **Mobile-responsive** layout

## Sections

### About Tab
- Personal introduction
- Skills showcase with interactive hover effects
- Interests section

### Resume Tab
- Professional work experience
- Education history
- Portfolio projects

## Getting Started

Simply open `index.html` in your web browser to view the portfolio website.

Alternatively, serve it with a local web server:

```bash
# Using Python 3
python3 -m http.server 8000

# Then visit http://localhost:8000 in your browser
```

## Files

- `index.html` - Main HTML structure with semantic markup
- `styles.css` - CSS styling with modern design and responsive layout
- `script.js` - JavaScript for interactive tab switching

## Browser Support

Works on all modern browsers including:
- Chrome/Edge
- Firefox
- Safari
